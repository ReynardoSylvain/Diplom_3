# Автотесты для Stellar Burgers

## Описание проекта

Этот проект представляет собой набор автоматизированных тестов, разработанных для проверки функциональности веб-приложения [Stellar Burgers](https://stellarburgers.nomoreparties.site/).

Целью проекта является обеспечение качества веб-приложения Stellar Burgers путем автоматической проверки основных сценариев пользовательского взаимодействия, таких как:

*   Переходы между разделами сайта (Конструктор, Лента заказов, Личный кабинет).
*   Функциональность конструктора бургеров (добавление ингредиентов, оформление заказа).
*   Работа личного кабинета пользователя (авторизация, история заказов, выход из аккаунта).
*   Восстановление пароля.
*   Отображение и детализация заказов в ленте заказов.

## Начало работы

### Установка зависимостей

1.  Клонируйте репозиторий проекта на свой локальный компьютер.
2.  Перейдите в корневую директорию проекта в терминале.
3.  Установите зависимости проекта из файла `requirements.txt`:
    ```bash
    pip install -r requirements.txt
    ```
